# 고정 기억 원화

세 이미지는 내장 `image_gen`으로 제작한 과거의 완성 원본입니다. 현재 귀·꼬리 수정 프롬프트는 `generation_prompts-anatomy-v3.json`에 있으며, 화풍 제작 기록은 `generation_prompts-style-v2.json`, 최초 기록은 `generation_prompts.json`에 보존합니다. 까망이가 오기 전의 장면이므로 세 이미지에 까망이는 등장하지 않습니다.

현재 원화는 프로젝트의 참고 이미지와 같은 큰 호박색 눈·둥근 체형·선명한 윤곽선·황금빛과 보랏빛의 판타지 저택 화풍을 사용합니다. 보송의 흰 털·머리 앞으로 낮게 접힌 귀·빨간 방울 스카프, 이파리의 주황·흰 털과 꽃 달린 모자, 도레의 짙은 회색·흰 털과 건반 장식 리본을 세 장에서 이어 갑니다.

| 파일 | 장면 | 공개하는 방 |
|---|---|---|
| `memory_01.png` | 비를 피해 온 어린 보송을 기다리는 할머니 | 1~4 |
| `memory_02.png` | 세 고양이가 각자 편히 지내는 공용 거실의 오후 | 5~8 |
| `memory_03.png` | 폭풍 속에서 함께 온기를 잃는 세 고양이 | 9~12 |

모든 고양이는 한 몸에 꼬리 한 가닥입니다. 보송의 귀는 서 있는 삼각귀나 귀 끝만 굽은 형태가 아니라, 머리에 가깝게 앞으로 접힌 귀입니다.

원본 PNG의 위치·표정·조명은 진행도나 엔딩에 따라 변경하지 않습니다. 특히 마지막 그림은 진엔딩 뒤에도 폭풍의 밤입니다. 현재의 해방 장면은 게임의 별도 연출입니다.

게임은 `kkamang/ui/memories.py`에서 원본을 읽고 1280×720 캔버스에 맞춥니다. 공개 영역은 같은 파일의 의미별 마스크로 나누며 썸네일에서도 미공개 영역을 가립니다. 모든 원본은 1672×941의 불투명 PNG이며, 생성 시 16:9 비율의 1픽셀 반올림 오차만 허용합니다. 원화 자체는 크기 변경이나 후처리 없이 보존합니다.

새 이미지를 교체하면 얼굴·발·손·소품·반투명 외곽·온기 입자의 위치를 확인하고 공개 마스크도 함께 조정해야 합니다. `tests/test_memory_art.py`는 원본 로드·불변성·누출 방지와 배포 환경의 Pygame 전용 실행을 검사합니다. Windows 빌드는 기존 `KkamangManor.spec`의 `assets` 폴더 포함 규칙을 사용합니다.
