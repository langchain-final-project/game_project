# 까망이와 잠 못 드는 저택 · v0.2.0

## 시작하기

Python 3.12를 사용합니다. Windows는 `RUN_WINDOWS.bat`, macOS/Linux는 `sh run.sh`로 실행합니다. 첫 실행에는 패키지 다운로드 연결이 필요합니다.

직접 실행하는 공통 명령:

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

게임 실행에는 Pygame만 필요합니다. Gymnasium·NumPy는 강화학습 환경/검증용입니다. Pillow는 화면 증거 재생성 도구에만 필요합니다.

## 이번 버전의 목표

각 방에서 **필수 물건 1개 + 온기 4점 이상**을 챙겨, 출발했던 문에서 E를 누르세요. 악보·책·담요 등 물건을 빠뜨리면 온기가 충분해도 완료되지 않습니다. 조건 미충족 귀환은 안내를 띄우며 탐사를 계속합니다.

- 방향키/WASD: 이동 및 온기 자동 수집, E: 같은 칸의 필수 물건/샛문 장치/귀환, Space: 대기, Esc: 일시정지.
- 이동하지 않아도 0.3초마다 시간이 흐릅니다. 메뉴·일시정지·창 포커스 상실 중에는 멈춥니다.
- 고양이는 칸 중간에서도 방향을 바꾸고 키를 떼면 멈춥니다. 입력은 다음 1/60초 이동 프레임에 반영되며, 한 칸 거리를 이동하는 속도는 0.3초로 유지합니다. E는 한 이동 프레임을 사용하고, 누르고 있는 방향키로 이어서 이동합니다.
- 온기는 +1 8개, +3 2개로 합계 14점입니다. 큰 온기는 순찰 주변에 있습니다.
- 2번·7번 방의 자석은 밟으면 즉시 소모됩니다. 주변 3×3의 +1 온기만 벽·닫힌 문과 관계없이 끌어오며, +3 온기는 직접 밟아야 획득합니다. 남은 13틱은 세계 틱마다 감소합니다. 효과는 방을 다시 시작하면 초기화됩니다.
- 3번 `[7,5]`·5번 `[12,2]`·11번 `[14,6]`의 무적 아이템은 밟으면 즉시 피해를 막습니다. 남은 10틱은 세계 틱마다 감소하며, 보호 표시와 추격 유령의 접촉 정지가 유지됩니다. 다음 방으로 효과를 가져갈 수 없습니다.
- 순찰 유령 접촉 시 용기 1 감소, 다음 3틱 보호. 온기는 차감하지 않습니다.
- 제한시간 또는 용기 소진 시 실패하며 그 판의 확정 점수는 0입니다. 이전 기억·별·꾸미기는 유지됩니다.
- 필수 물건은 점수를 대신하지 않습니다. 첫 성공으로 방 복원·기억 그림의 영역 하나·다음 방을 얻습니다.
- 온기 10점 이상 귀환 / 무피해 완료는 각각 선택 배지 1개를 남깁니다. 꾸미기는 최신 `main`의 별점 규칙을 따라 누적 별 6·12·18개에 목도리·러그·액자 선택지가 열립니다.

## feature/story · 스토리 제안서 개정 3.0

본편은 대사와 설명 자막 없이 그림과 행동으로 진행합니다. 프롤로그·탐험·쉼터·기억 공개에는 회상 대본을 표시하지 않으며, 조작법·아이템 이름·귀환 조건·진행도는 기능 안내로 유지합니다.

앨범은 다음 세 장으로 구성합니다. 각 그림은 같은 완성 원본의 불규칙한 영역 네 개를 누적 공개하며, 이미 공개된 인물·소품·조명은 바뀌지 않습니다. 아직 열리지 않은 부분은 작은 미리 보기에서도 가립니다.

| 기억 | 스테이지 | 제목 |
|---|---|---|
| 1 | 01~04 | 문이 열리던 밤 |
| 2 | 05~08 | 세 개의 자리 |
| 3 | 09~12 | 놓고 싶지 않았던 밤 |

기억 원본은 아래 PNG 세 장입니다. 각 파일은 네 단계 동안 공유하는 한 장의 완성 그림이며, 공개 마스크는 원화의 인물·소품 배치에 맞췄습니다. 공개 화면과 앨범은 원래 그림의 비율을 유지하며 전체 구도를 보여 줍니다.

- `assets/art/memories/memory_01.png`: 문이 열리던 밤
- `assets/art/memories/memory_02.png`: 세 개의 자리
- `assets/art/memories/memory_03.png`: 놓고 싶지 않았던 밤

과거 원화에는 까망이가 등장하지 않습니다. 세 번째 원화는 해방 뒤에도 폭풍의 밤을 유지합니다. 하부의 불투명한 몸·꼬리는 담요와 먼저 공개하고, 얼굴·윗어깨의 유령화·흩어지는 온기는 마지막 영역에서 공개합니다. 저장·공개 순서·귀환 조건을 유지하며, 엔딩 연결은 아래 여섯 결말 규칙을 따릅니다. 원화와 내장 이미지 생성 도구의 사용 프롬프트는 `assets/art/memories/`에 함께 보존하며, 기존 Windows 빌드의 자산 포함 규칙을 사용합니다.

- 해당 방의 첫 성공 귀환만 영역 하나를 영구 공개합니다. 실패·중도 포기·같은 방 반복으로 다른 영역이 열리지 않습니다.
- 부분 공개는 약 2초 뒤 쉼터로 돌아갑니다. 한 장을 완성한 4·8·12번 방과 앨범 다시 보기는 사용자가 넘길 때까지 기다립니다. 성공 결과와 보상은 공개 연출 전에 확정됩니다.
- 세 장은 모든 엔딩이 공유하는 과거입니다. 12개 방을 마친 뒤에는 `main`과 같은 `likes.select_ending`이 대표 기억의 호감도와 방별 최고 별 기록으로 여섯 결말 중 하나를 선택합니다. 대표 기억의 유지/교체 선택이 남아 있으면 먼저 선택을 마칩니다. 점수가 없는 옛 기록은 결말을 임의로 만들지 않고 호감도 화면에서 확인합니다.
- 새 결말은 무대사 정원문 장면 → 해당 친구의 개별 또는 전체 해방 → 선택된 원래 엔딩 그림 → 기존 후일담 순서입니다. 해방 대상이 없는 결말은 해방 장면을 건너뜁니다. `sad`는 대사가 없으며 그림에서 넘기면 쉼터로 돌아갑니다. `main`의 여섯 그림·제목·후일담을 보존합니다.
- 온기 10점 기록과 방별 `rich` 배지는 수집 통계입니다. 이를 12개 모았다는 이유로 베스트 엔딩을 선택하거나 쉼터에서 자동 해방하지 않습니다. 앨범의 `0/4~4/4` 진행도와 수집 배지, 엔딩 조건은 구분합니다.
- 저장 버전 4의 `likes.seen_endings`는 본 엔딩 ID를, `narrative.active_ending`은 새 결말 연출로 확정한 현재 세계를 기록합니다. 명시적인 다시 보기는 그림부터 열리고 감상 기록을 남길 수 있지만 현재 세계는 바꾸지 않습니다. 재탐험·앨범 재생도 현재의 해방 상태를 바꾸지 않습니다.
- 기존 `photos`·대표 기억·호감도·별점·꾸미기·6종 감상 기록을 보존합니다. 그림 영역은 `completed`에서 계산하며 사진만으로 영역이나 온기 기록을 만들어 내지 않습니다. 옛 `basic_seen`·`true_seen`·`liberation_seen` 값도 호환용으로 보존하되 여섯 결말의 판정·감상 이력·해방 상태를 자동 생성하는 근거로 쓰지 않습니다.
- 쉼터의 거리·빈자리·작은 행동으로 관계를 보여 줍니다. 기억 1·2 완성에 따라 음악 구절을 더하고 현재 활성 엔딩의 해방 상태를 표시합니다. 세 번째 원화는 어떤 결말 뒤에도 과거의 폭풍 밤을 유지합니다.

분기에는 완료한 방과 점수가 있는 대표 기억·최고 별 기록이 모두 필요합니다. 호감도는 각 친구의 정규화된 0~100 값이며 다음 순서로 판정합니다.

| 우선순위 | 조건 | 엔딩 | 해방되는 친구 |
|---|---|---|---|
| 1 | 세 친구 모두 호감도 70 이상 | `happy_all` · 아무도 남겨두지 않은 아침 | 보송·이파리·도레 |

기억 원화는 프로젝트의 큰 호박색 눈·둥근 캐릭터·선명한 윤곽선·황금빛 판타지 저택 화풍에 맞춰 제작했습니다. 세 친구의 방울·모자·건반 리본도 같은 디자인을 사용합니다. 보송은 머리 앞으로 낮게 접힌 귀를 사용하고, 모든 고양이는 꼬리 한 가닥으로 표현합니다. 현재 국소 수정 프롬프트는 `assets/art/memories/generation_prompts-anatomy-v3.json`, 화풍 제작 기록은 `generation_prompts-style-v2.json`에 있습니다.

여유 모드는 최신 `main`의 연습 전용 규칙을 따릅니다. 연습 결과는 완료·기억 그림·온기 회수·별·호감도·엔딩을 갱신하지 않습니다. 1·2번 방의 배치, 정밀 시간 표시, 새 랜턴·조작 안내도 최신 `main`을 유지합니다.

새 그림에는 글자를 굽지 않습니다. 고양이는 `assets/art/kkamang.png`의 4방향 대기와 방향별 걷기 6프레임을 탐사·쉼터·대화에서 공유합니다. 원본 PNG를 수정하지 않고 불규칙한 프레임 영역을 잘라 같은 몸통·발 기준으로 정렬합니다. 현재 표정 전환과 목도리 색상 변경은 적용하지 않으며 이미지의 빨간 목도리를 사용합니다. 무적 보호막과 피격 중 걷기는 유지합니다. 배경·가구는 기존 표시를 사용하며 독립적인 새 게임 판정은 UI에 추가하지 않습니다.

탐사 유령 A/B/C는 `assets/art/a.png`, `b.png`, `c.png`를 각각 사용합니다. 4열×2행의 8방향 자세 중 이동 방향에 해당하는 그림을 선택하고 기존 부유·직선 보간을 유지합니다. 정지·충돌 후 대기·일시정지 재개 시 마지막 이동 방향을 유지합니다. 쉼터·대화·호감도 화면은 보송=a, 이파리=b, 도레=c로 같은 PNG를 사용합니다. 엔딩 ID `ghost_b`(도레)와 탐사 유령 ID B(이파리 그림)는 별도 의미이므로 혼동하지 않습니다.

기억 그림은 별도의 완성 PNG 원화 세 장을 사용합니다. 공개 화면과 앨범은 원래 비율을 유지하며, 게임 실행 의존성은 Pygame으로 유지합니다.

## 개발용 바로 실행

```sh
python main.py --dev-stage 7
python main.py --dev-screen home
python main.py --dev-stage 7 --dev-screen story
python main.py --headless --no-audio --frames 5 --dev-stage 12
```

개발 옵션은 임시 저장을 사용하고 모든 방을 미리 열어 줍니다. 일반 플레이의 완료 기록을 만들지 않습니다. 지정한 `--save-path`도 개발 옵션과 함께 쓰면 무시됩니다. 일반 실행의 기본 저장은 사용자 데이터 폴더의 `KkamangManor/save_v02.json`이며 v0.1 저장을 덮어쓰지 않습니다.

## 같은 기준으로 검증

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q
python tools/replay_validation.py
python tools/evaluate.py --episodes 10 --output reports/local
```

검증 범위와 실행 명령은 `docs/VALIDATION.md`, 변경 이력은 `docs/CHANGELOG.md`에 있습니다. 기존 `evidence/`와 `validation/change_manifest.json`은 생성 시점의 자료입니다. v3 그림·가림막 검사는 `tests/test_memory_art.py`, 진행·저장·화면 전환 검사는 `tests/test_visual_story_campaign.py`와 `tests/test_visual_story_app.py`에서 확인할 수 있습니다.

현재 게임의 자유 이동을 학습하려면 `from kkamang.env import RealtimeMansionEnv`를 사용합니다. 한 행동은 1/60초이며 소수점 좌표와 세계 틱 진행률을 관측합니다. 기존 620차원 모델은 호환되지 않습니다. `tools/plan_routes.py`, `tools/evaluate.py` 및 기존 36개 경로 검증은 칸 단위 환경의 검사입니다. 그 결과를 자유 이동의 무피해 경로나 난이도 평가로 해석할 수 없습니다. 새 플레이 기록은 `python tools/replay_validation.py --record <기록.json>`으로 재생 검증합니다.

강화학습 모델은 아직 학습하지 않았습니다. Windows 실행 파일은 Windows에서 `BUILD_WINDOWS.bat`로 만들고 실제 PC에서 확인해야 합니다. 이 묶음은 팀 개발용 소스 배포본입니다.
