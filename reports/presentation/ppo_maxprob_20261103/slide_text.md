# 페이지 제목

학습 진행에 따른 고득점 귀환 성능

# 오른쪽 상단: 그래프가 보여주는 것

각 평가 시점에서 전12맵을 최대확률 행동으로 1판씩 실행했습니다.
세로축은 85점 이상 귀환한 맵 수입니다.
두 알고리즘 모두 seed 11로 각각 처음부터 학습했습니다.

# 오른쪽 하단: 관찰 결과

A2C는 학습 후반부에 12/12맵을 달성했습니다.
PPO는 최고 9/12맵을 달성했지만, 마지막 체크포인트에서는 5/12맵으로 감소했습니다.
PPO에서 학습 시점별 성능 변동이 관찰됐습니다.

# 하단 강조 문구

이번 실험에서는 A2C가 더 많은 맵에서 85점 이상 귀환했으며, PPO는 학습 후반에 성능 하락이 관찰됐습니다.

# 작은 각주

학습 seed 11의 단일 실행 · 유령 초기 위상 고정 · 평가 시점마다 맵당 1판 · 스텝은 4개 환경의 정책 결정 수 합계

# 그래프 사용 안내

- `maxprob_learning_curve.png`: 발표 배경과 어울리는 크림색 배경, 3300×1760픽셀.
- `maxprob_learning_curve_transparent.png`: 같은 그래프의 투명 배경 이미지.
- `maxprob_learning_curve.svg`: 확대 가능한 벡터 파일.
- `learning_curve_data.csv`: 실제 그래프에 사용한 평가 데이터 202행.
- `graph_metadata.json`: 원본 파일 해시, 비교 체크포인트와 결과, 가공 방식 기록.
- `make_graph.py`: 이미지 재생성 스크립트. 학습 코드를 실행하거나 변경하지 않습니다.

실선은 알고리즘별 101개 저장 평가값을 연결했으며 평활화하지 않았습니다.
단일 학습 seed이므로 여러 학습 seed의 평균·표준편차·신뢰구간을 표시하지 않았습니다.
연결선 사이의 값은 추가로 평가한 결과가 아닙니다.

표시한 발표 비교 체크포인트:

- A2C: 공유 모델, 9,709,436스텝, 12/12맵.
- PPO: 최대확률 평가의 85점 이상 귀환 맵 수 우선·동률 시 평균 점수 기준, 9,609,344스텝, 9/12맵.
- PPO 마지막 평가: 10,000,000스텝, 5/12맵.

원본 슬라이드의 '동일 사전 학습 모델에서 추가 학습', '세 학습 seed 평균', '시드 간 변동' 문구는 이번 실험에 맞게 교체해야 합니다.
