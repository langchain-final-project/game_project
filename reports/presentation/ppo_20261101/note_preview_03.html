3장 설명 · 성과를 어떻게 해석하나?

발표 대본

“평가는 준비된 중간 상태가 아닌 실제 시작점에서 진행했습니다. Stage 1 보관 모델은 새 시드 100판에서 성공률 96%, 별 3개 획득률 95%였습니다. Stage 2는 모델 선택 평가에서 성공률 96%, 별 3개 82%였고, 별도 새 시드 100판에서도 성공률 97%, 별 3개 78%를 확인했습니다. 자석 활용은 98%로 높았지만 평균 피해는 1.17회여서 유령 회피가 남은 과제입니다. 현재 무피해 추가 수집·귀환을 보강하고 있으며, 미확인 결과는 성과에서 제외했습니다.”

표에 사용한 실제 평가 수치

모두 실제 시작점의 확률적 100판입니다. Stage 1은 보관한 새 시드 평가, Stage 2 선택 평가는 최적 모델을 고르는 데 사용한 평가입니다. Stage 2 새 시드 평가는 선택 이후 다른 행동 난수 시드로 확인한 결과입니다. 새 맵에 대한 일반화 성능을 뜻하지 않습니다.

결정적 플레이와 확률적 플레이

결정적 플레이는 확률이 가장 높은 행동을 선택합니다. 확률적 플레이는 정책이 출력한 분포에서 행동을 뽑습니다. 최종 사용 방식에 맞춰 확률적 평가를 주 기준으로 사용했고, 결정적 플레이와 유령 초기 위상별 평가는 보조 지표로 기록했습니다.

Stage 2 결정적 화면 예시는 95점·별 3개·피해 1회입니다. 그 한 장면의 성공을 확률적 성공률 100%로 표현하면 안 됩니다. 같은 고정 환경에서 다른 시드의 결정적 재생이 같은 경로를 반복할 수도 있습니다.

이미 확인한 성과와 현재 목표

확인한 성과는 자석·물건·추가 수집·귀환의 연결입니다. 무피해 플레이의 안정성은 남은 과제입니다. 현재 마무리 설정은 성공 90%, 별 3개 90%, 평균 별 2.7개 이상과 평균 피해 0.1회 이하를 목표로 합니다. 학습 종료 후 선택한 모델 하나를 새 시드 200판으로 검증하도록 준비했습니다.

발표에서 구분할 것
부분 과제의 True ≠ 전체 게임 별 3개 성공
학습 중 성공률 ≠ 실제 시작점 평가 성공률
목표로 정한 기준 ≠ 이미 달성한 성과

발표 시점의 성과는 위 표로 고정했습니다. 진행 중인 마무리 실험의 최종 보고서가 확인되면 별도 근거와 함께 갱신해야 합니다.
