# 공통 디자인 기준

목표는 탐사·대화·홈에서 같은 까망이를 알아볼 수 있게 하는 것입니다. `kkamang/ui/illustration.py`가 실시간 이미지의 기준입니다. 기존 PNG는 참고 원본으로 보존하며 주요 화면에 혼합하지 않습니다.

## 캐릭터

기준 캔버스 160×180. 머리는 폭 118, 둥근 몸통 폭 80, 큰 삼각 귀, 황금 눈, 분홍 코, 세이지 목도리입니다. 몸/얼굴 비율은 화면별로 바꾸지 않고 전체 크기만 조절합니다. 네 발은 반대 위상의 왕복 운동, 몸은 작은 상하 움직임, 꼬리는 별도 움직임을 갖습니다.

- 방향: 앞/뒤/왼쪽/오른쪽. 뒤는 얼굴 대신 뒷머리 무늬, 좌우는 시선과 얼굴 중심 이동.
- 상태: idle 깜빡임, walk 발 움직임, collect 앞발 들기, surprised 커진 눈, happy 눈웃음.
- 탐사 수집/피해 이벤트가 표정을 바꿉니다. 대화는 프롤로그 놀람과 기억 장면의 기쁨/대기를 표시합니다.
- 방향별 8 phase를 코드로 그리는 방식입니다. 손으로 그린 32장 PNG 스프라이트 시트가 아닙니다.

## 화면과 소품

크림색 종이 패널, 나무색 테두리, 세이지/라벤더/복숭아 보조색을 사용합니다. 버튼은 기본·포커스/호버·강조·비활성 상태가 있습니다. 제목·본문·상태값은 동봉 폰트를 통해 Pygame에서 표시합니다.

탐사는 얇은 마루 이음과 연속 벽면, 창·문틀·책장·탁자·화분·러그를 구분합니다. 다음 위험 칸과 필수 물건 테두리는 장식보다 우선합니다. 가구는 막힌 칸에 놓고 캐릭터/가구는 바닥 y로 정렬합니다.

조명은 배경→약한 어둠→등불/온기 halo→캐릭터/상태 표시로 합성합니다. 홈의 복원등과 12개 소품은 완료 상태에 따라 등장합니다. 스카프·러그·액자 선택은 개별 레이어로 홈/앨범/꾸미기에 반영됩니다.

## 복원 피드백

수건/안내도/발자국 액자/책/고리/화분/악보/찻상/창/쿠션/합주/정원문이 순차적으로 남습니다. 읽는 책, 물방울, 음표, 찻잔 김, 반짝이는 박자로 주민 활동을 표현합니다. 이는 반복되는 작은 시각 연출이며 개별 주민 AI나 작업 시뮬레이션이 아닙니다. 새 방마다 완전히 다른 배경 일러스트 12장을 제작한 것은 아닙니다.

`evidence/`의 화면은 실제 렌더 결과입니다. 최종 화풍 선호는 팀이 직접 비교해 조정할 부분입니다. UI 개선도 버튼 영역·위험 가독성·렌더 성능에 영향을 주므로 테스트 대상입니다.
