# 사람이 확인할 조작감과 재미

자동 검증은 귀환 가능성과 규칙 일치를 확인합니다. 재미와 적정 난이도를 보장하지 않습니다. 제한시간은 기존 값에서 무작정 줄이지 않았습니다.

## 첫 플레이

1. 새 게임에서 방 1을 설명 없이 시작해 봅니다. 필수 물건과 온기 두 목표를 이해하는지 확인합니다.
2. 온기만 챙겨 귀환 E를 눌렀을 때 부족한 조건을 알 수 있는지 확인합니다.
3. 물건까지 챙겨 귀환했을 때 점수·사진·쉼터 소품의 연결이 느껴지는지 확인합니다.
4. 방 5/7에서 장치를 지나치거나 열어 보고 동선 이득이 보이는지 확인합니다.
5. 방 8/12에서 시간 압박 때문에 판단이 생기는지, 단지 키 입력에 쫓기는지 기록합니다.
6. 추가 온기 10점 배지를 위해 다시 도전하고 싶은지 이유를 묻습니다.

기록할 값: 처음 성공까지 시도 수, 실패 이유, 마지막 귀환 여유, 물건 미회수 귀환 시도, 장치 사용, 자발적 재도전, 위험 예고 이해 여부. 초보/재도전 값을 구분합니다.

## 난이도 조정 순서

목표 안내/시각 가독성 → 필수 경유 거리 → 위험 보상 위치 → 순찰 동시 판단 → 시간 여유 순서로 조절합니다. 한 번에 맵·유령·시간을 모두 바꾸지 않습니다. 새 요소를 도입하는 방에서는 시간 여유를 줘도 됩니다. 모든 방의 모든 숫자가 단조롭게 어려워질 필요는 없습니다.

현재 1은 수집/귀환, 2는 순찰 도입, 3~4는 깊은 경유, 5~6은 샛문, 7은 두 순찰, 8은 같은 구조의 시간 압박, 9~10은 두 장치 동선, 11은 복합 경로 정리, 12는 시간 압박입니다. 상세 수치는 LEVELS.md를 봅니다.

## UI 검수

걷는 발이 작은 화면에서도 보이는가, 좌우 방향을 구분하는가, 수집/놀람 표정이 읽히는가, 홈·대화의 같은 캐릭터가 자연스러운가, 버튼 포커스/비활성이 구별되는가, 큰 온기와 위험 칸이 겹쳐도 읽히는가, 창 크기 조절 후 클릭 위치가 맞는가를 확인합니다.

UI 통일은 완료했지만 최종 아트 선호와 난이도는 팀의 직접 플레이로 결정해야 합니다. 새 미니게임/전투/인벤토리/확률 드롭은 이번 범위에 추가하지 않았습니다.
