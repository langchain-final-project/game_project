# 맵 BGM 5곡 — 녹음 피아노 기반 재작업

대상은 `bgm_act1`, `bgm_act2`, `bgm_act3`, `bgm_stage12`, `bgm_ending` 다섯 곡이다. 로비, 피격·접촉음과 모든 효과음은 이 생성기에서 읽거나 변경하지 않는다.

이전 버전의 핵심 한계는 합성 건반의 음질과 긴 시간에 흩어진 단음이었다. 안쪽 성부도 가까운 음을 자동 선택해 같은 미·도가 반복됐다. 이번에는 **실제 어쿠스틱 그랜드 피아노 건반 녹음**과 새 악보를 사용했다. 기존 음원에 필터·볼륨만 바꾼 작업이 아니다.

- VCSL Kawai Grand의 CC0 건반 샘플을 원래 스테레오 그대로 사용한다. 가까운 건반을 최대 3반음만 이동하고, 약·중약·중간 강도의 녹음 층을 섞는다. 건반을 놓을 때는 녹음된 꼬리를 부드럽게 감쇠한다. 합성 패드·오르골·가짜 현악은 넣지 않았다.
- 공통 라–도–미에 **길게–짧게–유지**라는 리듬을 줬다. 도–시–라 응답, 네 마디 단위 질문·변주·응답·귀환을 명확히 적었다. 저음과 안쪽 성부도 모두 직접 작성했다.
- 기존 길이는 한 프레임도 바꾸지 않고 16마디 4박자로 구성했다. 문장 중간은 조금 흐르고 끝에서는 숨을 쉰다. 엔딩 마지막 두 마디에는 실제 시간 배치로 느려지는 종지를 만들었다.
- 실제 그랜드의 아주 짧은 해머 피크만 스테레오 연동으로 다듬었다. 강약 전체를 평평하게 만들거나 음표마다 정규화하지 않았다. 1dB 이상 감쇠되는 부분은 전체 프레임의 약 0.44~1.14%다.

| 곡 | 구성 | 길이 | 실제 RMS |
|---|---|---:|---:|
| 1막 | 낮은 음역의 조심스러운 질문, 떨어지는 저음선, 짧은 응답과 쉼 | 62.6087초 | -28.21dBFS |
| 2막 | 따뜻한 위 음역의 질문·친구 응답, 짧은 별도 윗성부 | 55.3846초 | -27.66dBFS |
| 3막 | 끊어진 자장가와 미–파의 작은 망설임, 짧게 누른 건반, 지속 드론 없음 | 68.5714초 | -28.93dBFS |
| 12스테이지 | 앞으로 가는 조용한 박자, 올라오는 안쪽 선율, 밝아지는 꼭짓점과 이완 | 57.6초 | -27.54dBFS |
| 엔딩 | 분명한 도–시–라 응답, 넓어진 선율, 솔에서 도로 완성되는 종지와 느려짐 | 67초 | -27.11dBFS |

다섯 WAV는 PCM16 / 22,050Hz / stereo다. 앞 네 곡은 음표 꼬리와 작은 방의 잔향을 원형으로 합산해 반복한다. 엔딩은 한 번 연주한다. 경계에만 큰 패드를 덧대거나 루프를 강제로 무음으로 만드는 페이드는 사용하지 않았다.

반복 마지막 마디도 새로 작곡했다. 1막은 시–솔♯–미–시, 3막은 미–솔♯–시가 다음 라로 이어진다. 2막은 미–솔, 12스테이지는 도–미–라의 짧은 진행이 다음 문장을 준비한다. 거의 들리지 않던 한 음의 꼬리 대신, 첫 선율과 비슷한 중약 터치의 실제 피아노 음표로 연결한다. 12스테이지의 마지막 착지는 경계 직전에 급하게 치지 않고 먼저 연주해 자연 감쇠가 경계를 가로지르게 했다. 엔딩은 이 연결부 수정에서 바꾸지 않았다.

## 출처와 재생성

원본 건반 녹음: [Versilian Community Sample Library](https://github.com/sgossner/VCSL), CC0-1.0. 사용 소스는 커밋 `c1ea7bcc3c7309650ab0da9d15c9cd1fbc4a4c7e`에 고정했다. 보존한 샘플 매니페스트에 원본 URL·건반 실제 MIDI 번호·강도 층·원본 SHA-256이 들어 있다. 샘플은 파일명 옥타브를 추측하지 않고 검증된 `root_midi`를 사용한다.

```bash
python tools/audio/generate_map_bgm_v7.py --sample-manifest .audio_work/piano/sample_manifest.json --output .audio_work/maps
```

오프라인 제작에 NumPy·SciPy와 보존한 샘플 뱅크가 필요하다. 게임 실행에는 완성된 WAV만 필요하다. `*.score.json`은 실제 음표 시각·길이·강약·역할·사용 녹음 층을, `map_bgm_v7_metadata.json`은 소스 고정값·길이·음량·루프 측정을 기록한다.

실제 건반 소리를 사용했지만, 이 곡 전체를 피아니스트가 연주해 녹음한 것은 아니다. 새 악보를 녹음 샘플로 렌더링한 음악이다. 별도 폴더 재생성의 해시·프레임·클리핑·경계는 수치로 검증한다. 사람의 청음이나 선호 평가를 완료했다고 주장하지 않는다.
