# v0.2 실제 검증 결과

## 자유 이동 전환 후 로컬 검사

- 전체 자동 테스트 297개, 하위 사례 137개 통과. 이 중 `tests/test_realtime.py`의 80개 검사는 기본 자유 이동 컨트롤러·공유 코어·전용 학습 환경을 검사합니다.
- 칸 중간 회전/반전, 정지 후 즉시 출발, 키 해제, 벽/닫힌 문 몸체 충돌, 틱 사이 수집/접촉, 무적/자석, 포커스 상실과 재시작, 이동 중 보호 그림을 검사했습니다.
- 10/30/60/120 FPS에서 같은 입력의 위치·세계 시간·유령 상태가 같고, 입력 연타로 세계 시간이 빨라지지 않음을 확인했습니다. 사람과 `RealtimeMansionEnv`의 매 이동 프레임 스냅샷/623차원 관측도 일치합니다.
- 기존 36개 경로의 각 명령을 0.3초 유지하는 자유 이동 검사에서 모두 해당 목표 온기 이상으로 완료했습니다. 일부 경로에는 피해가 발생하므로 기존 무접촉/무피해 주장을 자유 이동에 적용하지 않습니다.
- 기본 데스크톱 컨트롤러로 12개 방의 14점 귀환과 사진/완료/중복 정산 방지 저장을 검사했습니다.
- 새 자유 이동 완료 기록은 CLI로 254개 이동 프레임, 14개 세계 틱을 재생해 정산 결과 일치를 확인했습니다. `reports/local/realtime_input_record.json`은 무시되는 로컬 증거입니다.
- 별도로 기존 칸 단위 경로 재생 36/36, 레벨 해시 12/12, JSON 스키마 12/12, 7·11스테이지 headless 5프레임 실행을 통과했습니다. 새 칸 단위 재생 보고서는 `reports/local/realtime_legacy_grid_replay.json`입니다.

실제 모니터에서의 조작 체감, 원격 CI, 자유 이동 정책 학습과 난이도 재평가는 이 검사 결과에 포함되지 않습니다. 기존 칸 단위 `MansionEnv`/경로 도구와 현재 자유 이동 `RealtimeMansionEnv`는 구분해서 사용합니다. 자세한 관측 계약은 `RL_READY.md`에 있습니다.

## 기존 칸 단위 버전의 기록

아래 테스트 수·환경·난이도 평가는 기존 칸 단위 버전의 기록입니다. 현재 자유 이동 검증 범위는 위 항목을 따릅니다.

원본 v0.1의 테스트/이미지를 이번 결과로 재사용하지 않았습니다. 이전 검증 자료는 원본 보존본에 남기고 현재 패키지에는 v0.2 실행 결과를 넣었습니다.

- Python 3.12.14, pygame-ce 2.5.8, Gymnasium 1.4.0, NumPy 2.3.5, pytest 9.1.1 환경.
- 자동 테스트: 125개 통과, 하위 사례 54개 통과. `validation/tests_v02.txt`, `tests_v02.xml`.
- 12개 방 × 4/10/14점 귀환: 36개 경로를 실제 코어로 재생. 필수 물건 포함, 모두 무접촉 성공. `runtime_replay_results.json`.
- 별도 안전 경로 12개: 큰 온기·샛문을 사용하지 않고 필수 물건+4점 무피해 귀환. `safe_routes.json`과 테스트로 확인.
- JSON 스키마와 12개 레벨 일치 확인: `validation/schema_results.json`.
- 12개 방의 14점 행동열에서 사람용 GameCore와 AI용 MansionEnv의 매 틱 스냅샷/관측/종료 일치 확인.
- Gym `check_env`: 12개 방 × 기본/여유 모드. 관측 범위·seed 재현·종료/외부 truncation 구분 검사.
- 실제 Pygame 키 이벤트로 시작→스토리→탐사→귀환→사진/복원 저장→12개 방→엔딩 흐름 검사.
- 일시정지/포커스 상실/짧은 키 입력/저장 실패 재시도/중복 정산 방지 검사.
- 4방향·걷기 위상·수집/놀람/기쁨·목도리 변경의 실제 프레임 차이 검사. 주요 화면을 실제 렌더하여 PNG, 공통 rig를 GIF로 저장.
- 비교 정책 240판: 무작위 120판 0회 성공, 공개 정보 탐욕 120판 120회 성공, 오류 0. 탐욕 평균 확정 온기 13.03. **학습 결과 아님.**

## 미실행 또는 남은 확인

Windows exe 빌드/Windows 실기기 실행, 원격 GitHub CI, 사람 플레이 테스트, 실제 오디오 출력, 강화학습 학습/모델 평가/새 맵 일반화는 실행하지 않았습니다. SDL dummy 화면 검사는 실제 모니터·키보드 체감 테스트를 대신하지 않습니다.

기록된 경로는 현재 코어를 사용해 생성한 회귀 자료입니다. 독립적인 구현의 증명 또는 최적 경로 증명으로 소개하지 않습니다. 규칙 경계 단위 테스트와 사람/AI 동일 상태 검사를 별도로 수행했습니다.

화풍 만족도, 후반 시간 압박, 추가 수집의 매력은 팀 플레이에서 조정할 항목입니다. 현재 보상은 희소하므로 학습 실험은 RL_READY.md의 작은 단계부터 시작합니다.
