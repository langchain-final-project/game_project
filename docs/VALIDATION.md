## 미실행 또는 남은 확인

Windows exe 빌드/Windows 실기기 실행, 원격 GitHub CI, 사람 플레이 테스트, 실제 오디오 출력, 강화학습 학습/모델 평가/새 맵 일반화는 실행하지 않았습니다. SDL dummy 화면 검사는 실제 모니터·키보드 체감 테스트를 대신하지 않습니다.

기록된 경로는 현재 코어를 사용해 생성한 회귀 자료입니다. 독립적인 구현의 증명 또는 최적 경로 증명으로 소개하지 않습니다. 규칙 경계 단위 테스트와 사람/AI 동일 상태 검사를 별도로 수행했습니다.

화풍 만족도, 후반 시간 압박, 추가 수집의 매력은 팀 플레이에서 조정할 항목입니다. 현재 보상은 희소하므로 학습 실험은 RL_READY.md의 작은 단계부터 시작합니다.
