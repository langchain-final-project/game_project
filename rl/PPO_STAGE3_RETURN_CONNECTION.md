# Stage 3 수집 이후 귀환 연결 학습

## 이전 결과와 원인

분석 대상은 아래 실행입니다.

```text
reports/local/experiments/stage3_efficient_three_stars/quick/
seed_11_20261101_123909_108588
```

- 총 1,000,745 물리 프레임, 행동 선택 111,616회, 행동 유지 9프레임.
- 선택된 `best_model.zip`은 904,215프레임 평가 시점의 모델입니다.
- 최종 확률적 200판: 귀환 성공 0%, 별 3개 0%, 물건 획득 89%, 무적 획득 88.5%.
- 191판은 시간 초과, 9판은 용기 소진. 실제 피해는 판당 평균 0.36회입니다.
- 실제 시작점에서 시작한 학습 161판도 모두 실패했습니다.
- 반면 출구 근처 18~22번에서 시작한 학습은 418판 모두 귀환했습니다.
  수집을 거의 못 배운 상태가 아니라, 긴 벽 우회와 귀환을 연결하지 못한 상태입니다.

결정적 seed 11 재현에서는 온기 11점 상태로 `(7, 0.78)`과 `(7.5, 0.78)`을
오래 왕복했습니다. 당시 안내는 `(7, 1)` 또는 `(7, 0.78)`처럼 작은 중심 정렬을
요구했고, 9프레임 유지 행동과 정책의 방향 선택이 맞지 않았습니다.
필수 물건을 얻은 뒤에도 최종 `(6.28, 2.22)`에서 시간이 끝났습니다.
벽막힘 비율만 보면 실제 이동을 반복하는 이 실패를 충분히 설명하지 못합니다.

## 온기 10개와 10점의 차이

이 맵에는 온기 오브젝트가 10개이며, 1점 8개와 3점 2개로 총 14점입니다.
10개를 모두 수집하면 14점이지만, 온기 **10점**에서 귀환하면 별 3개가 불가능합니다.
현재 게임 규칙의 최고 시간 점수를 받았을 때 점수는 아래와 같습니다.

| 온기 점수 | 무피해 | 피해 1회 | 피해 2회 |
|---|---:|---:|---:|
| 10 | 76 | 71 | 66 |
| 12 | 88 | 83 | 78 |
| 13 | 94 | 89 | 84 |
| 14 | 100 | 95 | 90 |

별 3개 기준은 85점입니다. 동선을 줄이기 위해 기본 목표를 12점으로 두고,
현재 용기와 출구까지의 예상 이동 시간을 게임 점수 함수에 넣어 목표를 높입니다.
시간 점수가 최대인 조건에서는 무피해 12점, 피해 1회 13점, 피해 2회 14점입니다.
예상 귀환이 늦으면 필요한 온기를 추가로 높입니다. 예상은 현재 위치에서 출구로
직접 돌아가는 비용과 3틱 여유를 사용하므로, 남은 수집·물건 획득 시간까지
포함하는 성과 보장은 아닙니다. 여유가 부족하면 기존 생존 우선 귀환을 유지합니다.

## 이번 변경

1. 기존 Stage 3 `best_model.zip`의 가중치에서 시작합니다. 행동 출력은 1.0배로
   그대로 가져오며 최적화기는 새로 만듭니다. 원본 ZIP과 과거 결과는 보존합니다.
2. `stage3_waypoint_mode = corridor_lookahead_v1`에서만 새 경유지 안내를 사용합니다.
   몸체가 통과할 수 있고 최단 경로 비용이 증가하지 않는 직선 구간을 먼저 안내해,
   불필요하게 작은 중심 정렬 신호를 줄입니다. 실제 행동은 PPO가 선택합니다.
   이전 모델은 저장된 설정으로 기존 안내를 사용합니다.
3. 커리큘럼은 18번부터 다시 확장합니다. 기존 23개 준비 상태와 실제 게임 시간은 유지합니다.
4. 귀환 경로 거리의 감소·증가 보상을 새 안내에서만 칸당 ±1.0으로 보강합니다.
   같은 경로를 왕복하면 거리 보상 합계는 0입니다.
5. 짧은 실험은 추가 300,000 물리 프레임, 평가 간격 25,000프레임입니다.
   행동 유지 9프레임, 관측 640개, PPO 학습률 0.0001은 유지합니다.

| 시작 상태 선택 | 에피소드 선택 확률 |
|---|---:|
| 물건·온기가 준비된 긴 귀환, 13~18번 | 40% |
| 현재 진행 구간 | 40% |
| 초반 온기·무적 수집, 1~8번 | 5% |
| 물건 획득 전, 9~12번 | 5% |
| 실제 시작점 | 5% |
| 현재보다 뒤쪽 구간 복습 | 5% |

0번까지 진급하면 기존처럼 실제 시작점 80%, 뒤쪽 복습 20%가 됩니다.
이 표는 프레임 비중이 아니라 에피소드 선택 확률입니다.
현재 진행 구간에서 최근 20판 중 별 3개 16판이면 한 구간 앞으로 확장합니다.

## 실행과 확인

프로젝트 최상위 폴더에서 아래 명령으로 실행합니다.

```powershell
.\.venv\Scripts\python.exe -X utf8 -B -m rl.train_ppo --seed 11 --quick
```

저장 위치:

```text
reports/local/experiments/stage3_return_connection/quick/seed_.../
```

`--quick` 없이 실행하면 기존 100만 물리 프레임 예산을 사용합니다.
최적 모델은 준비 상태가 아닌 실제 시작점의 확률적 평가로 선택합니다.
먼저 귀환 성공이 0%에서 벗어나는지, 진행 구간이 18번에서 17~13번으로
확장되는지 확인합니다. 그다음 실제 시작점의 성공률·별 3개 비율·실제 피해를
함께 확인합니다. 최종 기준은 성공률 90%, 별 3개 90%, 평균 별 2.7 이상,
평균 피해 1회 이하이며, 새 시드 70,000~70,199의 200판도 유지합니다.

이번 수정 시 학습은 실행하지 않았습니다. 9프레임 간격으로 목표 안내를 따르는
규칙 행동 검증은 실제 시작점에서 온기 12점·필수 물건·무피해 88점,
874 물리 프레임에 완료했습니다. 준비된 긴 귀환 구간도 9프레임 제어로
별 3개 완료 가능함을 검증했습니다. 이 수치는 PPO가 배운 성능이 아닙니다.
수정 전 가중치로 새 안내를 재생한 소수 판도 아직 실패했으므로,
실제 개선 여부는 사용자가 실행할 새 학습의 평가 결과로 판단해야 합니다.
