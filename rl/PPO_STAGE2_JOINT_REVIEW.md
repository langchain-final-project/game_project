# Stage 2 초반 수집·물건 획득 공동 복습

이 문서는 이전 실험 설정입니다. 물건 획득 성능 하락을 확인해
현재는 [자석·물건 연결 PPO](PPO_STAGE2_MAGNET_CONNECTION.md)를 먼저 실행합니다.

현재 기본 실행은 물건만 얻고 종료하는 부분 과제에서 전체 게임 PPO 학습으로 돌아갑니다.
목표 순서는 **초반 온기·자석 → 물건 → 온기 14점까지 추가 수집 → 귀환**입니다.
물건 획득 시 에피소드가 끝나지 않으며, 별 3개 클리어를 계속 연습합니다.

## 이어 학습할 모델

`rl/ppo_config.py`의 `TRANSFER_CONFIG.model_path`는 다음 모델을 가리킵니다.

```text
reports/local/experiments/stage2_quest_acquisition/quick/
seed_11_20261101_022742_575649/models/best_model.zip
```

새 시드 각 50판에서 6번 94%, 7번 92%로 물건 획득을 통과한 모델입니다.
기존 ZIP은 보관하고 가중치를 새 PPO 모델로 가져옵니다. 행동 출력 배율은 1.0이며,
부분 과제 때 사용한 0.3 완화를 다시 적용하지 않습니다. 최적화기는 새로 시작합니다.
전체 게임 보상으로 복귀하고 학습률은 0.00005, 반복 학습은 10회입니다.

## 시작 상태 혼합

진행 구간이 0번에 도달하기 전, 첫 에피소드를 제외한 재시작 비중입니다.
이 확률은 에피소드 선택 비중이며 프레임 비중은 에피소드 길이에 따라 달라집니다.

| 연습 | 선택 비중 | 시작 상태 |
|---|---:|---|
| 처음부터 전체 과정 | 20% | 0번, 실제 시작점 |
| 초반 온기·자석 수집 | 25% | 1~5번, 자석·물건 미획득 |
| 물건 획득 후 계속 진행 | 20% | 6·7번, 자석 획득·물건 미획득 |
| 유령 근처 무피해 수집 | 15% | 11~14번, 실제 대기 0·9·18프레임 |
| 뒤쪽 수집·귀환 복습 | 10% | 현재 진행 구간보다 뒤쪽 |
| 현재 진행 구간 | 10% | 최초 9번, 별 3개 귀환을 익히면 앞쪽으로 이동 |

진행 구간이 0번에 도달하면 처음부터 80%, 뒤쪽 복습 20%로 전환합니다.
시작 상태는 실제 게임 이동으로 준비하고, 그 뒤의 행동은 PPO 정책이 선택합니다.
게임 화면 평가에서는 준비 경로 없이 실제 시작점에서 정책만으로 플레이합니다.

## 평가와 모델 선택

30,000 물리 프레임마다 같은 평가 시드로 다음 항목을 확인합니다.

- 실제 시작점의 확률적 100판: 성공률, 별 3개 획득률, 평균 별, 자석 활용, 실제 피해.
- 6·7번 각 확률적 20판: 물건 획득 성공률을 따로 기록. 결정적 결과는 참고용.
- 1~5번 각 확률적 20판: 180프레임 안에 자석 획득 후 실제 원격 온기 수집까지 하는지 확인.

부분 과제 결과는 `evaluation/step_*/evaluation.json`의 `skill_review`에 저장합니다.
부분 과제 성공률은 전체 게임 성공률과 구분합니다.

추가 학습 전 기준값은 물건 6번 95%, 7번 95%, 초반 자석 원격 수집 53%입니다.
자석 수집 53%는 준비된 1~5번 구간의 합계이며 실제 시작점의 전체 성공률이 아닙니다.
기준 결과는 `checks/baseline_skill_review.json`에 기록했습니다. 이 점검에는 PPO 학습이 없습니다.

`best_model`은 물건 획득 능력 보존을 먼저 확인합니다. 6·7번 중 낮은 성공률이
80% 이상인 후보를 우선하고, 두 구간 각각 90%·초반 자석 활용 80%를 회복하기 전에는
더 약한 기술의 성공률 개선을 우선합니다. 두 기술을 회복하면 전체 성공률·별 3개 획득률로 비교합니다.
6·7번 중 하나라도 80% 미만인 평가가 두 번 연속 나오면 학습을 중단하고 기존 최적 모델을 보관합니다.

정식 통과 기준은 확률적 성공 90% 이상, 별 3개 90% 이상, 평균 별 2.7 이상,
자석 활용 80% 이상, 평균 피해 0.1 이하이며 부분 과제 복습 기준도 함께 충족해야 합니다.
`--quick` 결과는 정식 통과로 표시하지 않습니다. 이후 학습 없이 새 시드 평가로 확인합니다.

## 실행

프로젝트 최상위 폴더에서 실행합니다.

```powershell
# 연결과 출발 모델의 6·7번 새 시드 성능만 확인: 학습·저장 없음
.\.venv\Scripts\python.exe -X utf8 -B -m rl.train_ppo --seed 11 --quick --check

# 전체 과정 공동 복습: 추가 300,000 물리 프레임
.\.venv\Scripts\python.exe -X utf8 -B -m rl.train_ppo --seed 11 --quick
```

`--quest-only`를 붙이면 이전 물건 전용 과제가 실행되므로 이번에는 붙이지 않습니다.
결과는 `reports/local/experiments/stage2_joint_review/quick/seed_.../`에 저장합니다.
`best_model.zip`은 선택한 모델, `last_model.zip`은 마지막 모델,
`final_model.zip`은 선택한 모델의 복사본입니다. 원본 부분 과제와 Stage 1 모델은 그대로 보관합니다.

300,000은 환경 4개가 진행한 물리 프레임의 합입니다. 행동은 최대 9프레임 유지되므로
행동 선택 횟수는 대략 33,000회이며 종료 프레임에 따라 달라집니다.
학습 예산과 평가 주기는 `TRAIN_CONFIG.quick_timesteps`, `quick_checkpoint_interval`에서 조정합니다.
다음에 공동 복습 체크포인트에서 이어갈 때는 `TRANSFER_CONFIG.model_path`만 바꾸고 배율 1.0을 유지합니다.
시작 전 새 시드 물건 획득 검증을 다시 통과해야 합니다.
