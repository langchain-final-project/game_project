# Stage 3 동선 계획과 별 3개 PPO

이 문서는 최초 100만 프레임 실험 설정입니다. 해당 결과를 분석한 뒤 적용한 현재 설정과
실행 방법은 [Stage 3 귀환 연결 학습](PPO_STAGE3_RETURN_CONNECTION.md)을 참고하세요.

Stage 2는 기존 최적 모델로 보관하고, Stage 3 학습 결과를 별도 폴더에 만듭니다.
게임 레벨 JSON·충돌·유령·별 점수 규칙은 변경하지 않습니다.

## 맵과 목표

Stage 3 `액자 회랑`은 격자 크기가 16×9로 같지만 이동 가능한 면적이 넓고 벽 우회가 큽니다.
출발점과 출구는 (1,1), 필수 물건은 (11,7), 무적 아이템은 (7,5)입니다.
순찰형 유령 A는 중앙의 3점 온기 두 개 주변을 순찰합니다. 무적 지속 시간은 게임 규칙상 10틱입니다.

별 3개는 최종 점수 85점 이상입니다. 온기 13점이면 속도 만점에서 무피해 94점,
피해 1회는 89점입니다. 피해 2회는 84점이므로 추가 수집 여유가 있으면 목표를 14점으로 높입니다.
기본 클리어 조건인 온기 4점·필수 물건·출구는 유지합니다.

## 목표 안내가 달라진 부분

1. 무적 획득 전에는 1점 온기를 기본 4점까지 모으면서 무적 아이템으로 가는 비용을 함께 계산합니다.
2. 무적 활성 중에는 가까운 중앙 3점 온기를 우선합니다.
3. 이후에는 남은 온기, 필수 물건, 출구를 함께 고려한 부분집합 동적 계획법으로 다음 수집 목표를 선택합니다.
4. 벽과 닫힌 문을 반영한 BFS 거리와 다음 경유지를 사용합니다. 가까운 아이템 하나만 계속 쫓지 않습니다.
5. 추가 수집 중 필수 물건을 이미 갖고 있다면 출구를 중간 경유지로 안내하지 않습니다.
6. 귀환 거리와 여유 3틱을 고려해 시간이 부족하면 기본 조건 확보·귀환을 우선합니다.

이 계산은 지형과 목표 순서를 돕는 계획이며, 유령 움직임까지 포함한 실제 행동 최적성을 보장하지 않습니다.
실제 이동·대기와 회피는 PPO 정책이 선택합니다. 유령을 자동으로 피하는 행동 마스크는 추가하지 않았습니다.
관측은 640개, 행동 유지 최대 9프레임을 유지합니다.
과거 모델에 `stage3_route_plan` 설정이 없으면 기존 목표 안내를 유지합니다.

## 출구 직전부터 역순 확장 + 수집·물건 복습

23개 시작 상태 중 **22번, 출구 진입 직전**에서 첫 에피소드를 시작합니다.
현재 구간 최근 20판 중 별 3개 성공 16판이면 구간 번호를 하나 낮춰 0번 실제 시작점으로 확장합니다.

| 재시작 구간 | 비중 |
|---|---:|
| 실제 시작점 | 15% |
| 초반 온기·무적·중앙 수집, 1~8번 | 25% |
| 오른쪽 구역·필수 물건 획득 전, 9~12번 | 20% |
| 현재 진행 구간 | 기본 30% |
| 이미 연습한 뒤쪽 구간 복습 | 10% |

첫 진행 구간인 22번에는 더 뒤쪽 구간이 없으므로 그때 복습 10%는 현재 구간에 합쳐집니다.
0번까지 도달하면 실제 시작점 80%, 이전 구간 복습 20%로 전환합니다.
비중은 에피소드 선택 확률이며 프레임 비중과 다릅니다.
상태 준비에 사용한 게임 시간·온기·무적 잔여 시간은 유지하고, 준비 중 획득 보상은 다시 주지 않습니다.

## 전이 모델과 보상

출발 ZIP:

```text
reports/local/experiments/stage2_magnet_connection_full/quick/
seed_11_20261101_032919_437907/models/best_model.zip
```

원본 파일은 보존합니다. 새 모델에 정책·가치 특징을 가져오고 행동 출력 가중치·편향만 0.5배로 완화합니다.
Stage 3 무적 직후 구간의 위쪽 목표에서 원본은 오른쪽 확률이 약 85%, 위쪽 약 1.5%였습니다.
완화한 초기 모델은 오른쪽 약 58%, 위쪽 약 7.8%입니다. 아직 학습 성과가 아니며 탐색 기회를 늘린 초기화입니다.

- 학습률 0.0001, PPO 반복 10회, 엔트로피 계수 0.01, clip 0.2, 새 최적화기.
- Stage 3 물건 획득 +5, 물건 접근 칸당 +1.
- 기본 4점까지 온기 점당 +0.5, 4점 초과 점당 +1.1.
- 무적 아이템 최초 획득 +1. 준비 상태에 이미 있으면 다시 지급하지 않음.
- 시간 비용 프레임당 -0.002, 실제 피해 회당 -1.5.
- 기존 별 3개 완료 보상과 무피해 별 3개 보너스 +2.

Stage 2의 자석 평가 하한과 무피해 0.1회 기준을 Stage 3에 그대로 적용하지 않습니다.
Stage 3의 주 기준은 실제 시작점 성공률 90%, 별 3개 90%, 평균 별 2.7 이상이며 평균 피해는 1회 이하로 둡니다.
무적 획득률·행동 수·피해량도 별도로 기록합니다.

## 실행

프로젝트 최상위 폴더에서 실행합니다. 이전 부분 과제 옵션과 `--from-connection`은 붙이지 않습니다.

```powershell
# 연결 확인: 학습·모델 저장 없음
.\.venv\Scripts\python.exe -X utf8 -B -m rl.train_ppo --seed 11 --quick --check

# Stage 3 PPO: 최대 약 1,000,000 물리 프레임
.\.venv\Scripts\python.exe -X utf8 -B -m rl.train_ppo --seed 11 --quick
```

결과: `reports/local/experiments/stage3_efficient_three_stars/quick/seed_.../`
평가 간격은 50,000프레임이며, PPO 수집 묶음 끝에서 평가하므로 예산을 조금 넘을 수 있습니다.
최소 200,000프레임 이후 실제 시작점 성능 기준을 두 번 연속 통과하면 조기 종료합니다.
100만 프레임 안에 모든 구간을 끝내거나 목표를 달성한다고 미리 보장하지 않습니다.

최적 모델은 실제 시작점 평가에서 선택합니다. 커리큘럼 성공률만으로 최종 성능을 판단하지 않습니다.
선택한 모델 하나는 학습 종료 후 새 시드 70,000~70,199의 확률적 200판으로 자동 검증합니다.
`training_summary.json`의 `final_stage3_passed`와 `final_verification/evaluation.json`을 확인합니다.
최적 모델은 `best_model.zip`, 마지막 모델은 `last_model.zip`, `final_model.zip`은 최적 모델의 복사본입니다.

```powershell
# 저장된 Stage 3 조건으로 평가만 재실행
.\.venv\Scripts\python.exe -X utf8 -B -m rl.evaluate_ppo --model "이번실행폴더/models/best_model.zip" --final-stage3

# 실제 시작점의 확률적 게임 화면 재생
.\.venv\Scripts\python.exe -X utf8 -B -m rl.watch_ppo "이번실행폴더" --stochastic --seed 11
```

준비 경로는 실제 규칙으로 무피해 100점·별 3개 완료 가능한 것을 확인했습니다.
새 목표 안내를 규칙 행동으로 따라가는 별도 점검도 13점·89점·별 3개로 완료했습니다.
두 검증은 경로의 실현 가능성을 확인한 것이며 PPO 학습 결과가 아닙니다.
`checks/transfer_baseline_smoke.json`은 출력 완화 전의 소수 판 전이 진단,
`checks/initialization.json`은 0.5배 완화한 새 모델의 초기 행동 확률입니다. 실제 PPO 학습은 실행하지 않았습니다.
