# Stage 2: 자석 → 물건 → 추가 온기 → 귀환

이 문서는 이전 실험 기록입니다. 물건 획득 독립 과제는 통과했고,
현재 실행은 [자석·물건 연결 PPO](PPO_STAGE2_MAGNET_CONNECTION.md)입니다.
이 문서의 전체 과제는 구간별 새 시드 평가 통과 후 `--from-quest`로 복귀할 때 사용합니다.

환경은 RealtimeMansionEnv, 알고리즘은 PPO입니다. Stage 1 확정 모델은 변경하지 않습니다.
현재는 이전 Stage 2의 `ppo_702181.zip` 가중치에서 새 최적화기로 미세 조정합니다.
이 후보는 기존 실제 시작점 평가에서 별 3개 12%, 평균 별 0.42개였습니다.
이전 `best_model.zip`은 일반 성공률 우선 규칙으로 선택됐으며 별 3개는 3%였습니다.

## 목표와 시작 상태

새 모델은 기본 온기 2점 이후 자석을 안내하고, 자석 획득 직후 물건을 우선합니다.
물건 획득 후 온기 14점 수집과 귀환을 안내합니다. 위험 시 기존 안전 귀환 기준을 유지합니다.
`quest_after_magnet`이 없는 과거 모델은 재생할 때 기존 목표 순서를 유지합니다.
목표 안내를 입력으로 사용하며 실제 이동·대기 행동은 PPO가 선택합니다.

초기 진행 구간은 9번이며 이후 역순 진급은 유지합니다. 에피소드 시작 혼합은 다음과 같습니다.

| 종류 | 비중 | 시작 상태 |
|---|---:|---|
| 물건 획득 전 | 40% | 6~8번: 자석 보유, 온기 4점, 물건 미획득 |
| 유령 근처 수집 | 20% | 11~14번: 물건 보유, 온기 6점 |
| 전체 시작점 | 10% | 0번: 물건·온기 미획득 |
| 쉬운 구간 복습 | 10% | 현재 진행 구간보다 뒤의 상태 |
| 현재 진행 구간 | 20% | 처음에는 9번 |

첫 에피소드는 진행 구간에서 시작합니다. 0번까지 진급하면 원래 시작점 80% 연습을 적용합니다.
유령 연습은 합법적인 준비 이동 뒤 0·9·18프레임 실제 대기를 추가합니다.
게임 시간·자석 잔여 시간·유령 이동이 모두 함께 진행되며 준비 대기에 획득 보상을 주지 않습니다.
CSV의 `curriculum_phase`와 `curriculum_ghost_wait_frames`로 혼합 종류와 대기를 구분합니다.
진급은 기존처럼 해당 시작점에서 별 3개로 전체 게임을 완주한 결과를 사용합니다.

## 짧은 학습 실험

학습률 0.0001, 반복 10회, 행동 유지 9프레임, 관측 640개를 유지합니다.
`--quick`은 추가 300,000 물리 프레임(약 33,000회 행동 선택), 평가는 30,000프레임 간격입니다.
결과는 `reports/local/experiments/stage2_quest_first/quick/seed_...`에 저장합니다.

```powershell
# 연결 확인: 학습·저장 없음
.\.venv\Scripts\python.exe -X utf8 -B -m rl.train_ppo --seed 11 --check --quick

# 학습은 사용자가 실행
.\.venv\Scripts\python.exe -X utf8 -B -m rl.train_ppo --seed 11 --quick
```

## 물건 획득·무피해 수집의 부분 진단

```powershell
.\.venv\Scripts\python.exe -X utf8 -B -m rl.probe_stage2 --model "학습실행폴더/models/best_model.zip"
```

각 시작점에서 확률적 3판씩, 최대 180 물리 프레임만 확인합니다. 학습은 하지 않습니다.

- 물건 과제: 6~8번에서 직접 물건을 획득하면 성공(총 9판).
- 유령 과제: 11~14번에서 추가 피해 없이 온기 14점까지 수집하면 성공(총 12판).
- 성공하거나 유령 과제에서 실제 피해가 발생하면 해당 진단 판을 종료합니다.
- 이는 부분 과제이며 전체 게임 성공률·별 획득률로 해석하지 않습니다.

같은 시작점·시드의 학습 전 진단은 `probes/baseline/probe.json`에 저장했습니다.
현재 목표 순서를 적용한 원본 가중치의 기준값은 물건 과제 33.3%, 유령 과제 83.3%입니다.
진단 환경의 정렬된 준비 상태에서 얻은 수치이므로 실제 시작점의 전체 성능과 다릅니다.
과거 체크포인트를 새 목표 순서로 진단하려면 `--current-goals`를 명시합니다.

전체 평가는 여전히 실제 시작점의 확률적 성공률 90%·별 3개 90%·평균 별 2.7개,
자석 활용률 80% 이상·평균 피해 0.1회 이하를 확인합니다. 유령 초기 위상별 평가도 유지합니다.
먼저 물건 과제의 개선과 전체 평가의 물건 획득률 상승을 확인하고 장기 학습 여부를 결정합니다.
