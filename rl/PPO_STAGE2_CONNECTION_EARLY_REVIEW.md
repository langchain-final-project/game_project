# Stage 2 연결 모델의 0·1번 추가 복습

이 연결 복습과 전체 수집·귀환 학습은 완료했습니다. 현재 기본 실행은
[무피해 추가 수집·귀환 마무리](PPO_STAGE2_SAFE_RETURN_FINAL.md)입니다.

첫 연결 학습은 기존 평가를 통과했지만 새 시드 각 50판에서 0번 80%, 1번 68%였습니다.
6·7번 물건 획득은 96%, 98%를 유지했습니다. 이번에는 그 모델을 보관하고
0·1번 초반 수집을 더 자주 연습하는 새 실행을 만듭니다.

## 출발 모델과 시작 비중

`rl/ppo_config.py`의 `CONNECTION_TASK_CONFIG.source_model`:

```text
reports/local/experiments/stage2_magnet_connection/quick/
seed_11_20261101_031141_705856/models/best_model.zip
```

행동 출력 배율 1.0으로 정책·가치 가중치를 그대로 가져오고 최적화기는 새로 시작합니다.
학습률 0.00005, 반복 10회, 실시간 관측 640개, 행동 유지 최대 9프레임을 유지합니다.
자석 범위 안내와 보상은 첫 연결 과제와 같습니다.

| 환경 | 시작 상태 선택 |
|---|---|
| 초반 수집 환경 2개 | 0번 40%, 1번 40%, 2~5번 각각 5% |
| 물건 복습 환경 1개 | 6번 고정 |
| 물건 복습 환경 1개 | 7번 고정 |

초반 수집 환경 안에서 0·1번 비중이 합계 80%입니다.
이 비중은 환경 전체의 프레임·에피소드 비중과 다르며 길이에 따라 실제 비중이 달라집니다.
고정 구간 평가에서는 시작 비중을 사용하지 않고 각 구간을 같은 판수로 평가합니다.

새 학습 중 평가 시드로 측정한 출발 모델의 기준값은 0번 78%, 1번 76%, 2번 86%,
3번 98%, 4번 98%, 5번 96%, 물건 6·7번 각각 100%입니다.
`checks/baseline.json`에 저장했으며 PPO 학습은 실행하지 않았습니다.

## 평가와 종료 조건

- 추가 예산: 약 150,000 물리 프레임. 평가 간격: 15,000프레임.
- 평가 시드: 20,000~20,049. 0~5번과 물건 6·7번을 각각 확률적 50판으로 평가.
- 0·1번 연결 성공률: 각각 90% 이상.
- 2~5번 연결 성공률: 각각 80% 이상.
- 물건 6·7번: 각각 90% 이상. 한쪽이라도 80% 미만인 평가가 두 번 연속이면 중단.
- 조기 정상 종료: **추가 30,000프레임 이상** 진행하고, 위 기준을 **학습 후 두 번 연속** 통과.

기존 평가 시드 10,000번대의 `True`를 새 실행의 종료 근거로 사용하지 않습니다.
출발 모델이 새 평가에서도 통과하더라도 최소 추가 학습과 연속 통과 조건을 적용합니다.
모델 선택은 물건 능력 보존을 우선하고, 각 구간의 목표 대비 가장 부족한 성공률을 개선하는 후보를 우선합니다.
전체 기준을 통과한 출발 모델보다 나은 후보가 없으면 출발 모델을 최적으로 보관할 수 있습니다.

`training_summary.json`에서 다음 항목을 확인합니다.

- `task_passed`: 최소 학습량과 연속 통과까지 충족했는지.
- `selected_evaluation_passed`: 선택한 모델이 평가 성공률 기준을 충족했는지.
- `consecutive_passes`, `selected_physical_frames`, `selected_quest_review`.

두 통과 값은 의미가 다릅니다. 예산이 끝나도 연속 통과가 부족하면 `task_passed`는 false입니다.
부분 과제 결과이며 전체 귀환·별 3개 성능과 구분합니다.

## 이번 실행

프로젝트 최상위 폴더에서 실행합니다.

```powershell
# 연결 확인: 학습·모델 저장 없음
.\.venv\Scripts\python.exe -X utf8 -B -m rl.train_ppo --seed 11 --connection-only --quick --check

# 0·1번 추가 복습 PPO
.\.venv\Scripts\python.exe -X utf8 -B -m rl.train_ppo --seed 11 --connection-only --quick
```

결과는 `reports/local/experiments/stage2_magnet_connection_early_review/quick/seed_.../`에 저장합니다.
PPO 수집 묶음의 끝에서 평가·종료하므로 예산을 조금 초과할 수 있습니다.
기존 연결 과제 모델과 평가 기록은 변경하지 않습니다.

## 통과한 뒤 새 시드 검증

새 모델에 저장할 최종 검증 시드는 **40,000~40,049**입니다.
이 시드는 학습 중 모델 선택에 사용하지 않습니다. 앞서 분석한 30,000번대와도 구분합니다.
`추가복습폴더`를 이번에 생성된 실행 폴더로 바꿉니다.

```powershell
# 새 시드 평가와 기록만 수행
.\.venv\Scripts\python.exe -X utf8 -B -m rl.train_ppo_connection --evaluate "추가복습폴더/models/best_model.zip" --heldout

# 새 시드의 구간별 기준 통과 후 전체 별 3개 수집·귀환 학습
.\.venv\Scripts\python.exe -X utf8 -B -m rl.train_ppo --seed 11 --quick --from-connection "추가복습폴더/models/best_model.zip"
```

복귀 명령은 모델에 저장된 구간별 목표와 최종 검증 시드로 확인한 뒤 전체 학습을 시작합니다.
과거 ZIP은 당시 저장된 80% 기준과 평가 시드를 유지합니다.
