# Stage 2 무피해 추가 수집·귀환 마무리

자석·물건·추가 수집·귀환을 익힌 최적 모델에서 이어서 유령 회피를 다듬습니다.
학습 완료 여부는 실제 시작점의 확률적 플레이로 판단하며 개선을 미리 확정하지 않습니다.

## 출발 모델

```text
reports/local/experiments/stage2_magnet_connection_full/quick/
seed_11_20261101_032919_437907/models/best_model.zip
```

선택 시점은 451,765프레임입니다. 기존 평가 성공 96%, 별 3개 82%, 평균 별 2.63개,
자석 활용 97%, 평균 피해 1.16회였습니다. 새 시드 100판도 성공 97%, 별 3개 78%, 평균 피해 1.17회였습니다.
결정적 플레이는 95점·별 3개였지만 유령 피해 1회가 반복됐습니다.
새 설정으로 학습 없이 확인한 출발 기준값은 `checks/baseline.json`에 저장했습니다.

원본 ZIP은 변경하지 않고 정책·가치 가중치를 배율 1.0으로 가져옵니다.
관측 640개, 실시간 게임의 이동·충돌·점수 규칙을 유지합니다.
학습률은 0.00002, PPO 반복 10회, clip 0.1, 엔트로피 계수 0.003입니다.
최적화기는 새로 시작합니다. 이미 익힌 경로를 크게 흔들지 않도록 작은 갱신을 사용합니다.

## 무엇을 집중 연습하나

| 시작 상태 | 재시작 비중 |
|---|---:|
| 실제 시작점부터 전체 과정 | 40% |
| 유령 근처 추가 수집·귀환, 9~14번 | 35% |
| 6·7번 물건 획득 후 계속 진행 | 10% |
| 자석 획득 전 1~5번 복습 | 5% |
| 뒤쪽 귀환 복습 | 5% |
| 현재 진행 구간, 최초 9번 | 5% |

첫 에피소드는 설정한 진행 구간에서 시작합니다. 비중은 재시작 선택 확률이며 프레임 비중과 다릅니다.
진행 구간이 0번이 되어도 위 혼합을 유지합니다.

유령 구간은 실제 0~135프레임 대기를 9프레임 간격으로 준비해 순찰 위상을 다양하게 만듭니다.
대기 중 게임이 끝나거나 피해를 받은 후보는 사용하지 않습니다.
준비로 경과한 시간·자석 잔여 시간·온기는 실제 상태를 유지합니다.
진행 구간 통과에는 별 3개와 무피해 귀환이 모두 필요합니다.
준비 경로는 시작 상태를 만드는 용도이며, 이후 행동은 PPO 정책이 선택합니다.

## 보상 변경

- 실제 피해: 회당 -1에서 **-6**.
- 보호 효과 없이 유령의 실제 몸체 중심에 1.1칸 이내로 접근하면 거리 비례의 작은 비용.
  프레임당 최대 -0.02이며, 실제 피해 벌점과 구분합니다.
- 무피해 완료 보상: +2에서 **+8**. **별 3개로 귀환할 때만** 지급합니다.
- 온기·자석 활용·물건 획득·별 보상은 유지합니다. 낮은 별로 빨리 귀환해 무피해 보상을 받지 못합니다.

행동을 대신 선택하는 유령 회피 마스크나 자동 대기 기능은 추가하지 않습니다.
현재의 실제 이동 가능 방향 마스크를 유지하고 회피·대기는 보상으로 학습합니다.

## 최적 모델을 어떻게 고르나

처음부터 성공 90%, 별 3개 80%, 평균 별 2.5개, 자석 활용 90% 이상을 성능 보존 하한으로 둡니다.
물건·자석 부분 평가도 유지합니다. 하한을 지킨 후보끼리는 다음 점수를 비교합니다.

```text
별 3개 획득률 - 0.20 × 평균 피해 + 0.10 × 무피해 성공률
```

최종 목표를 모두 충족한 후보를 먼저 선택합니다. 피해가 적어도 성공률·별 개수가 크게 떨어진 모델을 우선하지 않습니다.
기준 모델도 처음에 `baseline_model.zip`, `best_model.zip`으로 보관하므로 새 후보가 더 나쁘면 기준 모델을 유지합니다.
마지막 모델은 `last_model.zip`, 선택 모델은 `best_model.zip`이며 `final_model.zip`은 선택 모델의 복사본입니다.

## 이번 실행

프로젝트 최상위 폴더에서 다음 명령을 실행합니다. `--connection-only`와 `--from-connection`은 붙이지 않습니다.

```powershell
# 연결 확인: 학습·모델 저장 없음
.\.venv\Scripts\python.exe -X utf8 -B -m rl.train_ppo --seed 11 --check --quick

# 무피해 추가 수집·귀환 PPO 마무리
.\.venv\Scripts\python.exe -X utf8 -B -m rl.train_ppo --seed 11 --quick
```

예산은 **추가 최대 약 1,000,000 물리 프레임**, 평가 간격은 50,000프레임입니다.
PPO 수집 묶음의 끝에서 평가하므로 예산을 조금 넘을 수 있습니다.
최소 100,000프레임 이후 성능 기준을 두 번 연속 통과하면 일찍 종료합니다.
성능 보존 하한을 세 번 연속 놓치거나 물건 획득 복습 하한을 두 번 연속 놓치면 중단하고 최적 모델을 보관합니다.

결과: `reports/local/experiments/stage2_safe_return_final/quick/seed_.../`

## 학습 후 자동 최종 검증

학습이 끝나면 선택한 모델 하나를 **60,000~60,199 새 시드의 확률적 200판**으로 자동 평가합니다.
결정적 플레이와 유령 위상별 평가도 참고용으로 기록합니다. 이 결과로 모델을 다시 고르지 않습니다.

최종 통과 기준은 다음과 같습니다.

- 실제 시작점의 확률적 성공률 90% 이상.
- 별 3개 획득률 90% 이상, 평균 별 2.7개 이상.
- 자석 활용률 80% 이상, 평균 피해 0.1회 이하, 무피해 성공률 80% 이상.
- 물건·자석 부분 복습 기준 통과.

`final_verification/evaluation.json`과 `training_summary.json`의 **`final_stage2_passed`**를 확인합니다.
`quick` 실행의 `best_passed`는 정식 최종 통과 표시와 구분합니다.
검증이 끝날 때까지 기다려야 전체 절차가 완료됩니다. 모델과 함께 평가·설정 파일도 보관합니다.

검증만 다시 실행해야 할 때는 새 모델에 저장된 환경·평가 조건을 사용합니다.

```powershell
.\.venv\Scripts\python.exe -X utf8 -B -m rl.evaluate_ppo --model "이번실행폴더/models/best_model.zip" --final-stage2 --output-dir "이번실행폴더/final_verification"
```

이 명령은 학습을 수행하지 않습니다. 기준을 통과하지 않으면 미달 항목을 그대로 보고하고 기존 좋은 모델도 유지합니다.
