# Stage 2 자석·물건 연결 PPO

아래는 첫 연결 학습의 설정과 결과입니다. 현재 기본 실행은 통과한 연결 모델에서 이어가는
[0·1번 추가 복습](PPO_STAGE2_CONNECTION_EARLY_REVIEW.md)입니다.

이번에는 물건 전용 모델의 능력을 보존하면서 초반 온기·자석·물건 획득을 연결합니다.
실시간 게임 규칙과 별 점수 계산은 유지합니다. 학습·평가·화면 재생은 모델에 저장한 목표 설정을 사용합니다.

## 목표 방향과 자석 범위

관측은 **640개 그대로**입니다. 자석 위치·보유 여부·잔여 시간은 기존 630개 환경 정보에 포함되어 있고,
마지막 6개 목표 정보의 방향을 계산할 때 자석의 실제 규칙을 반영합니다.

- 자석 활성 중 1점 온기: 주변 3×3 범위의 이동 가능한 흡수 위치 중 가까운 위치를 안내합니다.
- 남은 자석 시간보다 이동 시간이 길면 온기 자체를 직접 밟는 위치를 안내합니다.
- 3점 온기: 자석으로 흡수되지 않으므로 직접 밟는 위치를 안내합니다.
- 수집 접근 보상: 다음 경유지까지의 단순 좌표 거리 대신 최종 수집 목표까지 벽을 반영한 경로 거리의 증감을 사용합니다.

`magnet_pickup_targets`, `collection_path_reward`를 새 모델의 목표 설정에 저장합니다.
과거 ZIP에 이 설정이 없으면 이전 목표 안내를 유지합니다. 새 관측 차원을 추가하거나 신경망을 초기화하지 않습니다.
준비 경로는 시작 상태를 만드는 용도이며, 이후 실제 행동은 PPO 정책이 선택합니다.

## Stage 2 보상 변경

| 항목 | 변경 전 | 변경 후 |
|---|---:|---:|
| 물건 획득 | +1 | +5 |
| 물건 접근, 칸당 | +0.5 | +1 |
| 처음 4점까지 일반 온기, 점당 | +0.1 | +0.5 |
| 4점 초과 일반 온기, 점당 | +1.1 | +1.1 |
| 자석 획득 | 없음 | 최초 1회 +1 |
| 실제 원격 수집 | 해당 온기 보상의 1.5배 | 유지 |

원격 수집에는 같은 온기의 일반 보상을 중복 지급하지 않습니다.
이동·대기의 시간 비용, 실제 유령 피해 벌점, 전체 별 3개 귀환 보상도 유지합니다.

## 먼저 실행할 연결 과제

출발 모델은 물건 획득을 통과한 다음 ZIP입니다.

```text
reports/local/experiments/stage2_quest_acquisition/quick/
seed_11_20261101_022742_575649/models/best_model.zip
```

행동 출력 배율 1.0으로 가중치를 그대로 가져오고 새 최적화기로 시작합니다.
PPO 학습률 0.00005, 반복 학습 10회입니다. 관측 640개, 행동 유지 최대 9프레임을 유지합니다.

- 환경 2개: 매번 0~5번 중 선택해 초반 수집부터 연습. 자석 획득·새로운 원격 수집·물건 획득을 모두 완료하면 부분 성공.
- 환경 1개씩: 6번·7번에서 물건 획득을 복습. 물건을 얻으면 부분 성공.
- 제한: 연결 과제 360프레임, 물건 복습 180프레임. 미달은 시간 제한 중단으로 처리.
- 연결 과제 완료에만 +5 추가. 6·7번 복습에는 추가 완료 보상 없이 전체 과제와 같은 물건 획득 +5 적용.
- 부분 성공을 게임 클리어·별 3개로 기록하지 않음. `connection_episode`로 별도 기록.

환경 배정 절반은 프레임·에피소드 비중 절반을 뜻하지 않습니다. 에피소드 길이에 따라 실제 비중은 달라집니다.

```powershell
# 연결 확인: 학습·모델 저장 없음
.\.venv\Scripts\python.exe -X utf8 -B -m rl.train_ppo --seed 11 --connection-only --quick --check

# 이번에 실행할 PPO 학습: 약 150,000 물리 프레임
.\.venv\Scripts\python.exe -X utf8 -B -m rl.train_ppo --seed 11 --connection-only --quick
```

15,000프레임 간격으로 평가하며 PPO 수집 묶음의 끝에서 평가·종료하므로 예산을 조금 넘을 수 있습니다.
0~5번 각각 확률적 20판에서 연결 성공 80% 이상, 6·7번 각각 90% 이상이면 일찍 종료합니다.
물건 성공률이 한 구간이라도 80% 미만인 평가가 두 번 연속 나오면 중단합니다.
최적 모델은 물건 능력을 보존한 후보에서 더 약한 구간의 연결 성능을 우선합니다.

결과: `reports/local/experiments/stage2_magnet_connection/quick/seed_.../`
로그: `quest_episodes.csv`의 `task_kind`로 연결 과제·물건 복습을 구분합니다.
`training_summary.json`의 `task_passed`는 연결 과제 결과이며 전체 별 3개 성능이 아닙니다.

학습 전 확률적 각 20판 기준값은 0~5번 연결 성공률이 순서대로 5%, 10%, 35%, 50%, 60%, 100%이고,
6·7번 물건 획득은 각각 95%입니다. `checks/baseline.json`에 기록했습니다.
기존 물건 전용 모델을 새 과제로 평가한 값이며, 새 PPO 학습을 실행한 결과가 아닙니다.

## 통과한 뒤 전체 별 과제로 복귀

아래 `연결학습폴더`를 방금 생성된 실행 폴더로 바꿉니다.

```powershell
# 새 시드 각 50판으로 연결·물건 능력 검증. 학습 없음
.\.venv\Scripts\python.exe -X utf8 -B -m rl.train_ppo_connection --evaluate "연결학습폴더/models/best_model.zip" --heldout

# 새 시드 기준을 통과한 모델로 전체 수집·귀환 PPO 학습
.\.venv\Scripts\python.exe -X utf8 -B -m rl.train_ppo --seed 11 --quick --from-connection "연결학습폴더/models/best_model.zip"
```

복귀 명령도 실행 전 새 시드 검증을 수행하고 미달이면 학습을 시작하지 않습니다.
전체 결과는 `reports/local/experiments/stage2_magnet_connection_full/quick/`에 저장합니다.
전체 예산은 `TRAIN_CONFIG.quick_timesteps`의 현재 값 500,000 물리 프레임입니다.
전체 과제에서는 물건을 얻어도 종료하지 않고 온기 14점·별 3개 귀환까지 연습합니다.
실제 시작점 성공률·별 3개 획득률·자석 활용·유령 피해와 6·7번 보존 평가를 함께 확인합니다.

기존 실패 실험의 `last_model`은 비교용으로 보관하고, 이번 출발 모델은 물건 획득 모델을 사용합니다.
설정과 코드 연결을 확인한 것만으로 학습 성능 개선을 확정하지 않습니다.
