# RealtimeMansionEnv Stage 1 — PPO 별 3개

Stage 1 최종 모델은 `reports/local/stage1/models/best_model.zip`입니다.
실제 시작점에서 온기 0점·물건 미획득으로 평가하며 목표는 성공률 90% 이상,
별 3개 획득률 90% 이상, 실패를 포함한 평균 별 2.7개 이상입니다.

## 확정 모델과 기록

- 모델 선택 평가: 확률적 100판, 성공 91%, 별 3개 91%, 평균 별 2.73개.
- 새 시드 평가: 확률적 100판, 성공 96%, 별 3개 95%, 평균 별 2.87개.
- 결정적 새 시드 20판은 모두 별 3개.
- 시드 11 확률적 재생: 31틱·온기 14점·100점·별 3개.
- 선택 시점: 마지막 미세 조정 실행의 122,351 물리 프레임.
- `best_passed: false`는 당시 `--quick` 진단 실행의 판정입니다.
  새 시드 정식 판정은 `evaluation/heldout_seeds/evaluation.json`에서 확인합니다.

보관한 `config.json`·`training_summary.json`은 원래 실험 기록이므로 경로를
소급 수정하지 않습니다. `model_manifest.json`에 원본 경로와 SHA256을 남깁니다.
주요 네 실험의 설정·선택 평가와 예전 문서는 `history/`에 있습니다.

## 관측과 행동

실시간 관측 630개 + 실제 이동 가능 방향 4개 + 목표 정보 6개 = 640개입니다.
환경과 목표는 별도 신경망으로 처리합니다. 목표 좌표는 가까운 경유지 기준
`0.5 + 0.5 * clip(상대 좌표, -1, 1)`로 표현합니다. 해당 설정이 없는 과거 모델은
이전 좌표 표현을 유지합니다. 이동 불가 방향과 효과 없는 상호작용은 마스크합니다.
실제 행동은 PPO가 선택하며 대기는 허용합니다.
1틱은 18물리 프레임이며, 같은 행동을 최대 9프레임 유지합니다.

## 보상과 커리큘럼

게임의 기본 온기 4점·필수 물건·출구 귀환 및 점수 85점 이상의 별 3개 판정은 유지합니다.
학습 안내는 온기 14점을 목표로 하며 4점 초과분은 점당 총 +1.1 보상입니다.
현재 수집 목표에 접근하면 보상하고, 수집 중 물건 접근·귀환 보상의 충돌을 방지합니다.
성공 보상은 `10 + 점수/10 + 별*6`이며 별 0/1/2/3개에 `-8/-6/-3/+10`을 추가합니다.
시간·벽막힘·정체에는 비용을 줍니다. 시간 12틱 미만 또는 용기 2 미만이면
기본 조건 확보와 귀환을 우선합니다.

실제 물리 경로의 29번(출구 직전)부터 0번(실제 시작점)으로 확장합니다.
현재 구간 최근 20판 중 별 3개 16판이면 진급합니다. 준비에 쓴 게임 시간은 유지하고
준비 상태에서 얻은 아이템의 보상은 다시 지급하지 않습니다.
최종 실행의 커리큘럼은 2번까지 진행됐지만 실제 시작점의 독립 평가는 목표를 통과했습니다.

## 추가 학습과 실행

Stage 1은 목표를 달성했으므로 추가 학습은 필수가 아닙니다.
현재 `rl/ppo_config.py`는 Stage 2용입니다. 학습 명령은 현재 설정을 사용하므로
Stage 2 실험은 [PPO_STAGE2_QUEST_FIRST.md](PPO_STAGE2_QUEST_FIRST.md)를 참고하세요.
Stage 1 재생은 보관한 설정을 읽어 현재 학습 Stage와 독립적으로 실행합니다.

```powershell
# 연결만 확인: 학습·저장 없음
.\.venv\Scripts\python.exe -X utf8 -B -m rl.train_ppo --seed 11 --check --quick

# 확정 모델 재생
.\.venv\Scripts\python.exe -X utf8 -B -m rl.watch_ppo "reports/local/stage1" --stochastic --seed 11
```
